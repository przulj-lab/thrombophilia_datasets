# A Phenotype Driven Integrative Framework Uncovers Molecular Mechanisms of a Rare Hereditary Thrombophilia

**N. Malod-Dognin, G. Ceddia, M. Gvozdenov, B. Tomić, S. Dunjić Manevski, V. Djordjević and N. Pržulj**

Corresponding author: Prof. N. Pržulj, natasa.przulj@mbzuai.ac.ae

</div>

This repository contains all data and scripts related to the paper "A phenotype driven integrative framework uncovers molecular mechanisms of a rare hereditary thrombophilia".

## Contents

**[codes](codes)**: five Python scripts and two text files:

- [Main_NMTF.py](codes/Main_NMTF.py)
- [NMTF_class_code.py](codes/NMTF_class_code.py)
- [Subnetworks.py](codes/Subnetworks.py)
- [Compute_enrichments_alls.py](codes/Compute_enrichments_alls.py)
- [Cluster_Associations_Thrombophilia.py](codes/Cluster_Associations_Thrombophilia.py)
- [Gene_clusters_all.txt](codes/Gene_clusters_All.txt)
- [Gene_clusters_all_P.txt](codes/Gene_clusters_All_P.txt)

**[processed_dataset.zip](processed_dataset.zip)**: the germline variant profiles of five subjects.
